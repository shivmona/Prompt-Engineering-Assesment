📌 Overview
This repository contains a structured assessment designed to evaluate foundational and advanced skills in prompt engineering. It includes tasks organized across multiple sections, emphasizing reasoning, prompt design, model evaluation, and creative use of language models.

🗂️ Repository Structure

Prompt-Engineering-Assesment/
├── SectionA/
│   └── [Files for task-based problems]
├── SectionB/
│   └── [Files for creative prompt generation]
├── SectionC/
│   └── [Files for evaluation, optimization, or advanced concepts]
├── requirements.txt
└── README.md
💡 Each section is self-contained and includes tasks designed to test specific aspects of prompt engineering. Refer to section-wise README files if present for more info.

⚙️ Installation Instructions
1. Clone the repo:

git clone https://github.com/shivmona/Prompt-Engineering-Assesment.git
cd Prompt-Engineering-Assesment

2. (Optional) Create a virtual environment:

python -m venv env
source env/bin/activate   # Windows: env\Scripts\activate

3. Install dependencies:

pip install -r requirements.txt

🚀 Usage Instructions
Run scripts in each section directly. For example:

python SectionA/task1.py
python SectionB/creative_prompt.py
